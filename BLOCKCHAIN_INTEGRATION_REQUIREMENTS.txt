## 1️⃣ WHAT YOU MUST PROVIDE: Registration Function

### Purpose
When a course is ready, Backend calls your function to register it on-chain and get an IP token.

### Function Signature (what we'll call)
```javascript
registerIP(metadata) {
  // Input:
  {
    fileCid: "QmXxxx...",           // IPFS hash of course file
    title: "Smart Contracts 101",   // Course title
    description: "Learn Solidity",  // Course description
    tags: ["solidity", "web3"],     // Array of topic tags
    creator: "0x123abc...",         // Creator's wallet address
    royalty: 10                      // Optional: royalty % (1-100)
  }
  
  // Output:
  {
    txHash: "0x789def...",          // Transaction hash
    ipTokenId: "ip_token_12345",    // ID of IP token created
    metadataHash: "QmYyyy...",      // IPFS hash of metadata
    status: "success"               // 'success' or 'error'
  }
}
```

### What This Function Should Do
1. Take the input metadata
2. Call Camp Origin SDK to register IP token
3. Return the results (txHash, ipTokenId, metadataHash)
4. Handle errors gracefully

### How Backend Will Call It
```javascript
// Backend endpoint: POST /api/courses/publish
app.post('/api/courses/publish', async (req, res) => {
  const { fileCid, title, description, tags, creator, royalty } = req.body;
  
  // Call your function (you need to expose this)
  const result = await blockchainService.registerIP({
    fileCic,
    title,
    description,
    tags,
    creator,
    royalty
  });
  
  // Store result in Backend DB
  // Return to Frontend
});
```

## 🔄 EXAMPLE FLOW (Complete)

```
1. Frontend creates course & uploads file
   ↓

     tempId: "temp_course_123",
     metadataHash: "QmYyyy...",
     creator: "0x123abc..."
   }
   ↓
6. Backend calls YOUR function:
   blockchainService.registerIP({
     fileCid: "QmXxxx...",
     title: "Smart Contracts 101",
     description: "Learn Solidity",
     tags: ["solidity", "web3"],
     creator: "0x123abc...",
     royalty: 10
   })
   ↓
7. YOUR FUNCTION:
   - Calls Camp Origin SDK
   - Registers IP token
   - Returns: {
       txHash: "0x789def...",
       ipTokenId: "ip_token_12345",
       metadataHash: "QmYyyy..."
     }
   ↓
8. Backend stores ipTokenId in database
   ↓

   {
     success: true,
```
